# Enfusion Actions

**[Visit the interactive website](https://josharghhh.github.io/enfusion-actions-site/)**

Animation tools for Arma Reforger creators: native TXA editing, motion controls, character and animal fitting, and Workbench workflows.

This public repository currently contains the project website and creator tutorial. The tool source remains in private development and will be published here when the creator approves it for release. No release date is promised.

## Explore

- A 1:49 creator walkthrough, with on-screen instructions and a written summary.
- Searchable feature cards with practical workflow notes.
- A setup checklist that saves progress in your browser.
- A roadmap that separates available features, experimental work and proposed additions.

**[Watch the tutorial](site/assets/creator-walkthrough.mp4)** · **[Report an issue or suggest a feature](https://github.com/josharghhh/enfusion-actions-site/issues)**

Detailed guide links on the website currently require access to the private development repository. This repository does not contain private source models, training datasets, local settings or the animation-tool code.

## Website maintenance

See [site/README.md](site/README.md) for local preview, content updates and deployment. GitHub Pages deploys only `site/`, so the website can stay separate when the approved tool source is added later.

The existing project mark and creator recording are used for this website. The video depicts Bohemia's public sample character, without distributing that source asset. Enfusion Actions is an independent project and is not an official Bohemia Interactive product.
